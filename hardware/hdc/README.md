# HDC lane and host packet contract (research draft)

No PCIe/DDR controller or bitstream is included. The host transport is a reference, not a DMA driver. The HDC1 request layout (little endian) is `magic[4], version:u8=1, opcode:u8=1, reserved:u16=0, request_id:u64, dimension:u32, prototypes:u32`, then one query and C prototype rows of ceil(D/64) uint64 words in LSB-first order, then CRC32 over preceding bytes. D=1..65536, C=1..256. Padding bits must be zero. The HDR1 response is `magic[4], request_id:u64, prototypes:u32`, C signed int32 bipolar scores, CRC32. Request identity, exact size, parity and range validated on return. CRC protects accidental corruption, not authentication. Request IDs are echoed, not replay-protection. Host custody/authorization, bounded queues, IOMMU and driver controls required before device access.

`score64.sv`: one 64-bit lane, input words with per-bit mask, `first` resets accumulation, `last` emits score. A beat is consumed iff valid&&ready. Output valid and score remain stable through backpressure; reset clears output/partial accumulation. Transport must enforce first/last ordering, mask and dimension limits; the lane is not a standalone packet parser. `score64_tb.sv` consumes independently generated cycle vectors checking signed masked accumulation, full dimension, partial tails, stalls, concurrent result retirement/input acceptance, and reset. Local oracle generation is not RTL execution; Icarus/Verilator unavailable locally. Run `python -m tools.cog03f_rtl --out ./cog03bc-artifacts` from repo root with Icarus and vvp installed. Actual Icarus execution is mandatory on the hosted Linux/3.11 cell. No synthesis, timing closure, power, PCIe negotiation or physical measurements.

Target device: xc7k325tffg900-2; confirm exact part on hardware. Do not generate carrier-dependent XDC/pin/PCIe configuration without verified carrier schematic, power and reference clock. Model banks: 64 data bits x 512 addresses per RAMB36 SDP (parity unused). Resource table is arithmetic, one bank per lane, class-major padded rows, separate query bank; no controller/FIFO/projection storage, ECC, clocks or LUT/DSP estimate. Full binary model resident on FPGA is a design option, not a completed feature. For device work, obtain Vivado report_utilization, report_timing_summary and actual negotiated PCIe speed/width; measure staged host traffic and on-device time and power independently. No inference of FPGA performance from CPU room-temperature timing.
