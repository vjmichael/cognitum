## Mathematical architecture

State is a point in a declared coordinate space/manifold; it is not automatically a true physical state or full history. A deterministic representation can be discrete x[k+1]=f_k(x[k],u[k]), y[k]=g_k(x[k],u[k]) or continuous dx/dt=f(t,x,u), y=g(t,x,u). Stochastic form uses transition and observation kernels p(x[k+1]|x[k],u[k]) and p(y[k]|x[k]); continuous diffusion models require a declared stochastic convention. Specify what is supplied vs estimated, known vs learned, and state observability/identifiability. Descriptor E dx/dt=Ax+Bu and PDE evolution M dq/dt+Kq=F are further profiles, not shoehorned into ordinary dense invertible state space. S4/Mamba families are distinct learned computational state spaces and do not by themselves estimate a physical latent state or confer statistical calibration.

**Core math contracts** (design, not available routes):
- ModelSpec: deterministic/stochastic/hybrid/learned profile; dimension, units, clock, transition and observation convention, coefficients/data/checkpoint/source, numerical precision, declared assumptions, allowed horizon and resource limits. Tiny exact-rational discrete profiles and independently checked float64 conventional solvers first. Separate real/complex and continuous/discrete, covariance PSD from arbitrary uncertainty, time-independent from time-varying, descriptor consistency from ordinary ODE. Stable, marginal, unstable and nonnormal are separately classified.
- Observation/Control/StateBelief: explicit event IDs, units, timestamps, mask, covariance/distribution or set, support, provenance, modality and admitted time horizon; predicted estimate vs filtered posterior vs smoother vs measured fact. Streaming state binds model/version, last consumed event and clock, RNG if needed, boundary convention and reset; no canonical fact writes.
- Operation families: model validation, transition/rollout, impulse/transfer and spectra, exact rank/realization, estimation/filter/smooth, identification/discovery, simulation/discretization, reduction, forecast/uncertainty, planning/control proposal, learned train/inference, certificate verification. Method-specific types instead of one arbitrary executable payload. Functions/data use reviewed declarative models or bounded existing KAN operator carriers. Do not introduce a new registry, host authorization, journal or privileged worker. No arbitrary code execution from a model request.
- Evidence: bind input/output/model hashes, source SHA, numerical type and solver version, assumptions, tolerances and residuals, witness/proof domain, trajectory/time span, uncertainty type, resource scope and refusal reason. Hashes are integrity rather than approval. Separate exact rational identities and independently replayable certificates, floating numerical residual/error, empirical prediction/calibration and qualitative exploratory outcomes. Sampled trajectories cannot establish universal stability/safety. Learned hidden state is not verified memory; causal forecasts require explicit causal assumptions.

### Exact and numerical foundation
For continuous linear time-invariant models, x(t+h)=exp(Ah)x(t)+integral_0^h exp(A(h-s))Bu(t+s) ds. For zero-order hold compute A_d and B_d via block exponential (including singular A), not A^-1 shortcut. For process diffusion compute Q_d by covariance integral, not generally hQ. Verify against independent scalar/diagonal analytic formulas, rational discrete recurrence and direct high-accuracy trajectory; in floating evaluation use scale/conditioning-aware thresholds, document uncertainty. Controllability/observability and Gramians have distinct assumptions. For a bounded rational discrete Lyapunov witness, verify P positive definite and P-A^T P A positive definite exactly; this gives a stability statement for the specified A, not all learned/noisy systems. Mark numerical search and exact checker separately. Kalman posterior exact conditional Gaussian under correct model, not a universal uncertainty claim.
