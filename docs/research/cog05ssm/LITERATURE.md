# State-space mathematical engine — literature map

Search cut-off 2026-11-20. Targeted discovery through public research search, publisher records/abstracts and upstream documentation; this is a breadth-first annotated source map, not a systematic review, exhaustive literature claim or completed paper-level reproduction. Publication status follows the retrieved record, preprints are not treated as independently validated. Review full methods, conditions, versions, licensing and benchmark code at each gate. Classic source dates and 2025–2026 frontier are both represented. No paper's reported performance is a Cognitum result.
