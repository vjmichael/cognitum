## Implemented

- Four bounded fixed-basis profiles: inherited strict B-spline (degree 0–3), Gaussian RBF, endpoint-clamped B-spline (degree 1–3), Chebyshev (degree 0–8). Clamping is a distinct profile, never a semantic change to the existing deployed spline. Fixed knots, binary masks, bias; no trainable SiLU base, no deeper than two layers, width ≤8, rows ≤2048. Numeric arrays bounded; masks, parameters and snapshots immutable.
- Analytic basis derivatives, Jacobians, Hessians and explicit composition chain rule; nonsmooth spline derivative requests refused conservatively; edge integrals using Gaussian erf and per-span polynomial quadrature. These are float64 estimates, not continuous rigorous enclosures of all KANs or full network integrals.
- One-layer augmented ridge least squares (no normal equations), two-layer deterministic backpropagation with bounded backtracking. Actual coefficient and bias updates, mask invariance, intermediate-domain rejection; no adaptive knot learning or general optimization. Local snapshots have strict versioned canonical bytes and pins, not authority. Export for strict spline/RBF uses the existing layers-only MEL KanInput binary32 profile; exact byte pin and round-trip validation. Clamped and Chebyshev refuse export: require reviewed new descriptors, codecs and numerical certificates before execution routes can advertise them.
- Genuine trained-spline and trained-RBF checkpoint scoped worker evaluation with independently replayed represented-input interval evidence. For a newly fitted scalar RBF checkpoint: existing MEL-05C VFA conversion certificate within 1e-10 value/gradient tolerance on [-1,1]. This certifies the represented functions, not accuracy against the unknown target. Actual separate KAN, VFA, VFA-baseline and HDC query worker calls via existing verified graph; replayed witness, Hamming [2,0,0], nearest ties [1,2]. Differently declared thresholds refuse exchange before HDC dispatch (three earlier calls retained). No new grant authority.

## Local Linux CPU evidence

Python 3.13.5 NumPy 2.3.5. 61 tests; independent SciPy basis and differential checks, finite differences, quadrature oracles, multilayer learning, immutable and tamper/shape/domain refusals, portable checkpoint parity, scoped actual worker and graph tests. Benchmark retains split data, hashes, fitted parameters, training loss histories, actual audit receipts, conversion/graph witness bytes. The single-layer diagnostic trains on 81 points, evaluates the 80 distinct interval midpoints for 0.4 sin(2x)+0.1x², fixed [-1,1] domain, ridge 1e-8. Holdout RMSE: Gaussian RBF 6.4541e-5; strict cubic spline 8.6454e-2 (negative control, poor outer-span coverage); clamped cubic 2.7867e-4; Chebyshev degree 5 1.0274e-5. Conventional parameter-count-matched polynomial fit also performs extremely well (e.g. RBF comparator 3.8917e-10); no KAN superiority claim. Cross-family parameter counts differ; conventional comparator has different regularization. Separate two-layer synthetic fit of .2x+.1x², 300 updates per family, holdout RMSE RBF 0.0030693; strict cubic 0.0260746; clamped cubic 0.0122672; Chebyshev 0.0022323. All are diagnostic interpolation, not out-of-distribution or scientific-learning proof. No scaling-law or hardware efficacy claims.
