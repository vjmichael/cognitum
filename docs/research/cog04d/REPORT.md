## Method

- Clamped B-splines degrees 1–3, one separated interior knot per input coordinate per insertion; maximum twelve knots per grid, two layers, existing width and coefficient bounds. Boehm insertion uses exact rational transport, then one binary64 rounding per coefficient. Independently reconstruct the old and rounded new ideal represented edge polynomials on the union of knot spans. Convert each residual to exact Bernstein coefficients in normalized coordinates; convex hull bounds the complete span (not a sample estimate). Propagate cumulative output residuals through reference layer Lipschitz bounds and conservatively verify both intermediate domains. This is an upper bound for ideal represented functions over the full declared input box, not execution rounding or learned-target accuracy. No derivative residual certificate claimed; derivatives independently sampled and existing MEL point witness checked. Conservative enclosure may refuse valid models. No strict-spline/RBF knot migration, adaptive grid relocation, knot removal or unrestricted layer shapes.
- Single-layer adaptive fit: fit fixed basis by existing least squares, score spans only by training squared residuals, split maximal residual span per input coordinate (deterministic ties), certify transport, refit; retain strict training MSE gain. At most four iterations. Refit intentionally changes function; transport certificate is not a certificate for refitting or predictive error. No optimality claim. Held-out midpoints not used for choosing knots or tuning. Synthetic experiment target exp(-30(x-.38)^2), 101 training points, 100 held-out midpoints. Four ordered knots 0.5, 0.25, 0.75, 0.375; local RMSE 0.18973712194931194 -> 0.009985774326156577, max pre-refit full-domain transport bound 2.7755575615628914e-17. More basis coefficients are used; no matched parameter/compute superiority claim.
- Structural pruning: ordered candidate edges by max absolute coefficient; mask a candidate, independently certify the cumulative output error relative to the ORIGINAL network, accept only if within budget, not per-edge budget alone. Full-domain output error, not a derivative or timing bound; no regrowth, rank or topology search. Retain immutable parameters, reject unproved intermediate domain. Tested weak-edge removal and cumulative budget refusal; network propagation through downstream polynomial Lipschitz bound.
- Freeze independently learned x^2 feature and fit a new Chebyshev head for x^4 on its activation, preserving the original layer object and snapshot identity. Validate disjoint midpoints and full-domain intermediate range; snapshot -> existing typed polynomial checkpoint -> explicit host review fixture -> existing model-facing route and actual worker. Two more actual worker requests for refined and pruned candidates. Receipt independently verifies represented point values/derivatives, not the target equation or training generalization. Local x^4 holdout RMSE 2.0572392763534501e-16, observed derivative values at x=.5 within 1e-12 of .0625/.5/3. Training checkpoints are not automatically approved by any of the learning or certification functions.
