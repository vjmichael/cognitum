## Implemented bounded research extension

- Lossless packed SDM hard addresses use existing PackedBank, portable popcount, retained exact counter arrays and reversible original-write arithmetic. Nine paired seed/dimension tests match dense activation, writes, subtractions and raw reads bit-for-bit; separate standalone backend, not yet compatible with D1B's explicit-address checkpoint. No automatic route or replacement of C08 authority.
- Signed Hopfield set sketch from Clarkson/Ubaru/Yang, [capacity analysis](https://arxiv.org/abs/2301.10352), Theorem 14/Corollary 33: signed symmetric outer products, constant diagonal and int32 strict upper triangle, seeded separate indexed sign streams. Frobenius inner product normalized by d² estimates overlap; unbiased under independent coefficient signs, exact exhaustive small expectation and dense-oracle tests. Triangular indices temporary. Distinguish this signed sketch from recurrent classical/modern Hopfield fixed-point capacity; iterative convergence/cycles and broader workload qualification remain in D2/G. Not a proof of finite PRNG independence or complete paper replication.
- [HRR structured queries](https://arxiv.org/abs/2606.13871) independent bounded reference inspired by normalized row/attribute binding. Deterministic domain-separated Gaussian atoms, HRR convolution and additive row bundling, per-column midpoint threshold; not the paper's exact summed-query thresholds. Conjunctions across distinct columns, equality/non-equality, IS NULL/IS NOT NULL; typed signed int64/text/NULL, row order IDs and duplicate row preservation. Tentative attribute projection via HRR correlation and cleanup. Independent snapshot digest/revision and exact symbolic row predicate/projection check of candidate IDs; caller must supply trusted current canonical rows. Verified subset can be incomplete; explicit complete fallback scans all canonical rows. No actual authorization claims, persistent duplicate fact store or canonical SQL replacement; existing C08 verifier untouched. Tests compare with SQLite and reject stale/forged IDs; subset verification does not independently authenticate the ranking. Actual paper datasets/source not reproduced; G remains open.
