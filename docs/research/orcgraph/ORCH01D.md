## Native source and exact mathematical implementations

- All datasets are host-provided original bytes qualified through ORCH-01B: explicit UTC event and first availability timestamps, declared units, source SHA-256, missingness, chronological 60/20/20 train/cal/test and train-only mean/standard deviation. Original `CandidateContract` and `assert_matched_cohorts` independently check identical forecast origins and targets for every candidate. No silent intersection, interpolation, imputation or future observed sensor force is allowed.
- `persistence` uses the measured origin value, `train_mean` reuses the training-only source scale, `direct_ridge` invokes the actual R4 `ssm_timeaware.ridge_fit/ridge_predict` with predeclared fixed ridge regularization, and `timeaware_ssm` invokes actual R4 `ssm_zoh_rate`, choosing its stable elapsed-time rate on train-only sample error. These are independently evaluated, not placeholders or copied reports.
- The explicitly opt-in research alternatives fit a real one-layer train-only Chebyshev KAN (`cognitum.research.kan_trainable.Network.fit_linear`/reviewable immutable snapshot) on SSM residuals, and a real HDC MAP (`Spec.bundle` and `Cleanup.propose`) on training-only regimes; with both enabled, `ssm_kan_hdc` composes capped KAN residual and HDC after-KAN bias. HDC proposal abstention, unseen KAN feature domains and frequency of fallback are retained, not cherry-picked from scoring. The KAN research snapshot is **not** a MEL-approved checkpoint; this workflow does not issue host tokens.
- `Fitted` records source identity, training-origin hash, train cutoff, R4 ridge parameters, stable SSM generator rate, opt-in KAN snapshot hash, HDC typed prototypes, residual caps and immutable model identity. `Calibration` scores candidates only on the calibration fold and selects by predeclared MAE/tie order; `evaluate_holdout` independently recomputes the calibration and rejects forged/post-hoc selection before ever reading test observations.
- Heldout table includes n/RMSE/MAE for every eligible candidate, **signed** gains relative to direct ridge (a negative gain is a loss), explicit eligible/skipped denominators and HDC/KAN abstention counters. A dependence-aware block audit uses strictly non-overlapping uninterrupted clock chunks, a 90%-nominal descriptive maximum-absolute-error radius from calibration only, test origin and simultaneous-block coverage and a deterministic paired block bootstrap. If contiguous block count is inadequate or original clock is irregular, intervals and bootstrap are explicitly refused, not fabricated. These are **not** conditional coverage guarantees, test-optimised model selection, physical causal evidence or established significance tests.
