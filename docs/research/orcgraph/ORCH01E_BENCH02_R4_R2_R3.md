### HDC/KAN functional audit and scientific limitations

The original `cognitum.research.kan_trainable.Network.fit_linear` is a **QR/SVD-style augmented ridge least-squares fit** of a *single layer fixed degree-2 Chebyshev basis* on two original standardized lag features, not an epoch-trained deep network. More passes over the same 35–88 train-origin examples cannot by themselves add unrepresented interactions or new weather observations. Additional genuinely new training cohorts and separately controlled KAN basis complexity, degree, regularization and compositional layers would be meaningful *future experiments*, not fixes justified by present heldout labels. The original HDC uses 256D MAP hypervectors, four coarse bins per input, just two median-temperature-based prototypes and a train-only residual/bias adapter; this is a valid actual HDC associative use, but **not a rich independent regime-discovery model**. Independent capacity/noise, stronger state encoding and actual improvement over KAN need new falsifiable studies. No confirmed algebraic coding defect was established by this particular native benchmark.
