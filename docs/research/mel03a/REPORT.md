Strict bounded ASCII JSON top-level object, duplicate keys including nested refused, no repair, excessive depth (>12), integer/decimal token-length limits, nonfinite and overflow refused, max 64 KiB. Closed fields axes/domain/terms/constant/output_unit/points; all nested objects closed; codec independently enforces cross-field axis alignment, finite strictly ordered domains, in-domain points, width and magnitude limits and unit label semantics using MEL-02 objects. Model-visible subset dimension 1–8, 0–32 Gaussian terms, 1–16 points, to bound context and result size; underlying MEL-02 engine retains 256 terms and 32 points. Units are tokens, no conversion. Immutable BoundCall carries reviewed descriptor identity, host-supplied request/correlation IDs and typed immutable function/coordinate objects; payload conversion produces the original Runtime shape only, never a grant or dispatch.

Typed result binding matches request/correlation/operation, contract, module/version, assurance, parent identities and metadata against the trusted runtime response. Fixed bounded error codes, no rejected private text, no automatic retries or misleading successful dry run. A valid hash/lineage does not attest independent mathematical truth or authenticity of arbitrary model-supplied results.
