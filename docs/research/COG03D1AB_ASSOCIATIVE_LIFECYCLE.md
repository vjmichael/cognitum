## D1B
DerivedAssociations is a disposable single-scope research cache, NOT a new canonical store. Keys use exact C08 role/entity BSC digest, bipolarized; values use domain-separated SHA256 source ID/revision. Fixed 256D, caller-supplied hard addresses; maximum 4096 source IDs and 128 changed rows per consecutive revision. Host authenticates snapshot, deltas, scope, current snapshot and record provenance; no access permission granted by cache. Immutable source record custody supports inverse subtraction only of original writes. Atomic staged counter copies, source ID replacement/insert, tombstone and rescope removal, count and overflow bounds, stale revision and duplicate delta refusal. Invalidation clears arrays and metadata and advances generation. Local RLock and reentrant-generation checks protect acquisition and verification; not a host/cross-process lock.

Candidate includes cache-instance nonce, snapshot, revision, generation, source ID/revision, score and margin. Recompute candidate from supplied probe, refuse forged/stale proposals or scope mismatch, call actual existing C08 verify_hdc_candidates using a deterministic one-candidate BSC request, independent host records and fresh snapshot. Exact source revision and citation must match original write; changed citation or same-relation newer write, missing, tombstoned, rescoped, wrong role/entity all abstain/reject. This verifies selected proposal, not complete retrieval or global SDM ranking; no probability calibration, auth or canonical authority. Host must serialize canonical acquisition and evidence use. Duplicate relation ties may abstain; no exact retrieval completeness guarantee.

Checkpoint is deterministic small witness of source metadata and array digests, including scope, config, snapshot, revision; neither a MAC nor stored full counters. Restore requires independently authenticated current canonical records; rebuild then compare exact witness. Refuse stale or tampered cache, do not treat checkpoint as authority. Fresh interpreter test uses a separate fixture; a test-only subprocess exits after writing and fsyncing a partial temporary checkpoint before replace. Last committed bytes remain intact, fresh process can rebuild and verify, old revision refused after canonical advance. This is simulated interruption and actual process restart, NOT evidence of native Lu durable transactional writes, power-loss handling or host crash custody. Engine performs no filesystem I/O. Host owns persistence and atomic durable publication. No local authorization service added.
