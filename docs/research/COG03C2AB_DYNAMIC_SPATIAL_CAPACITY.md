## Research scope and references

- ID-VSA [TVLSI 2026 paper](https://prefer-nsf.org/pdf/IEEE%20TVLSI_2026.pdf), Fig. 5/8, Section III-A/C: bit-reversed VDC counter comparator with explicit reset and emitted updated XOR toggle, QND mean over radix-inverse streams (fixed bases 2^1..2^log2(D), fixed slot thresholds, XOR with uniform radix stream). Exact scalar recurrence, seed-free replay and range limits. These are stated interpretations, NOT claimed recovered RTL/reset convention or complete ID-VSA reproduction. No-shift ordered n-gram using injective Cantor symbol/position mapping and indexed IID control; old IDs stable with growth. Immutable screened bank validates restored/admitted indices against absolute pair coherence, duplicate/antipode controls, atomic refusal and finite capacity. Three 64-row VDC audits, max absolute cosine 1, one antipode in each; QND max 1 or .99609375, one antipode at D128. Hadamard zero for tested full rows, IID max .328125/.15234375/.10546875 for dimensions 128/512/1024. Do not generalize a failure under our explicit convention to original RTL. Exact Gaussian Polygon and other variants still open; no true hardware RNG claim.
- [HyperSpace spatial](https://arxiv.org/html/2604.15113v2), table 1/Sections 3–4: same continuous position/value phase geometry, superposition binding and summation, inverse position, optional one-step similarity-weighted and softmax cleanup followed by softmax codebook regression. HRR is real inverse-FFT of Hermitian spectrum; direct FHRR stores full complex spectrum; half-FHRR stores positive frequencies only, weighted dot interior terms by two. Explicit endpoints and Hermitian constraints; tested independent Fourier equivalence, all three cleanup options, exact matched predictions within numerical tolerance. This is constrained geometry, not lossless compression of arbitrary FHRR. Decoder regenerates levels; cost included; no learned neural decoder or full paper benchmark.
- [HyperSPACE sparse adder](https://doi.org/10.1145/3816440.3818512), [author summary](https://yh-v5.github.io/works/oh2026hyperspace/): independent software analog using seeded Bernoulli sparse feature masks, threshold Bernoulli scalar levels, AND (noninvertible) versus XOR on same masks and levels, per-coordinate train-only median quantizer. Scalar independent counts and immutable threshold checks. Full circuit/learned threshold paper implementation not reproduced; no measured energy/device gain.
- [Capacity analysis](https://arxiv.org/abs/2301.10352), independent bounded oracles: odd-n sign-sum MAP-B conditional member correlation = C(n-1,(n-1)/2)/2^(n-1), exact finite binomial FN and FP for stated IID assumptions; exhaustive n=1,3,5,7,9 and 7-bit score controls. Bloom sparse union, with-replacement positions and canonical packed pad bits, Counting Bloom uint16 checked cardinality, exact finite occupancy recursion for small filters, FPR E[(R/m)^k]. Counting Bloom intersection expectation n*m*k²/M + overlap*k*(1-1/M) gives unbiased estimator under assumptions; verified enumeratively for small case. No exact-delete claim for read-only filters; reversible MAP-I preserves ID set. All approximate scores proposals only. More paper theorems (tree/structured/sparse capacity), actual data and update costs remain open.

## Local budget evidence

13 independent Linux child runs, single-thread BLAS, 512 MiB common RLIMIT_AS in process before model build (spatial child also launched with shell limit), peak RSS includes imports, benchmark input/oracle and build/query temporary buffers. This bounds address space, NOT equal observed RSS, nor a tight universal memory footprint equality. Read-mostly logical payload caps 4/16 KiB for set arms; array bytes + fixed logical descriptor/ID accounting, not exact serialized or Python object size. Other pilots report model arrays and observed RSS; no claim all models have equal retained bytes. All 13 runs finished; no hardware energy measurements.

Set membership: five fixed seeds × n=127/511 × two payload caps × 256 balanced member/nonmember queries = 5120 paired cases per arm (not 25600 independent cases); exact sorted uint32 IDs with both scalar and batched search, MAP-I, MAP-B, Bloom, Counting Bloom; same IDs/queries. All exact/MAP-B/Bloom arms had no observed errors across four cells each; not zero true error for probabilistic methods. Counting Bloom intersection absolute error means at n511: 10.53 (4 KiB), 4.11 (16 KiB); MAP-I 17.37/4.40, same overlap target but distinct disjoint IDs. Exact sorted-set baseline retains all IDs, a different inference/information contract than associative composition; clear win for this simple task. Process peak RSS ~138 MiB for common set pilots, dominated by runtime/imports and benchmark. No use of test labels for tuning.

Spatial: 25 fixed known training points, 16 held-out interior points on smooth synthetic scalar field, five frequency seeds. Exact shared geometry and useful compression, not established speedup or general task-quality advantage. Direct RBF much faster; more real workloads required.

Sparse encoded real sklearn digits: one fixed stratified held-out split of 450, 512 dimensions, projection density .02, median threshold from training only. AND 384/450 (85.33%), bound bit density .006327447 (~99.367% sparsity), XOR 182/450 (40.44%), density .31249293. No claim of optimal XOR baseline (same sparse-mask and quantizer only), or circuit efficiency. Strong SVC and future tuned HDC encoders remain required.
