## Wire and mathematical contract
Version cognitum.mel.object.v1. ASCII compact sorted-key JSON envelope with exactly id/body fields; id is SHA-256 of canonical body bytes. Canonical here means this version's encoder, not an arbitrary JSON or RFC-8785 serialization. Body has a closed field set. All numbers in mathematical payload encoded as little-endian IEEE-754 binary64 bytes, strict canonical base64, flattened row-major. Float domain endpoints are canonical Python float.hex strings; signed zero preserved in content identities. Shapes are bounded actual integers, not bools, and unknown representations, fields, duplicate keys, nonfinite values, noncanonical frames and invalid shape/range are refused. The object retains only an immutable string; callers receive fresh metadata copies and immutable value tuples. No Python executable or opaque deserialization, paths, generated expressions, arbitrary pickle, or permissions in mathematical data.

| Kind | Representation | Payload layout | Shape |
|---|---|---|---|
| function | diagonal_gaussian_mixture | constant, centers, widths, weights | [terms,dimension] |
| points | coordinate_batch | coordinates in declared order | [points,dimension] |
| values | scalar_batch | computed scalar per row | [points] |
| gradient | gradient_batch | partial derivatives per coordinate | [points,dimension] |

Each function is c + sum_i w_i exp(-1/2 sum_j ((x_j-center_ij)/width_ij)^2). Real-valued with diagonal anisotropic positive widths; constant-only permitted. Declared input domain is a closed finite Cartesian box, axes are unique ordered identifiers, and scalar codomain / gradient component units are encoded using numerator/denominator tokens. Unit labels require exact compatibility, do not implement conversion or physical dimensional analysis. A gradient component in output unit u for coordinate unit v is labeled [u,v]. The Gaussian kernel supplies derivatives of the represented function even at box boundaries, not a finite-width interpolation derivative certificate.

Bounds: 1–8 variables, 0–256 Gaussian terms, 1–32 query points per request, 65,536 ASCII bytes per input object, max 8192 output-object bytes within original 16384 output JSON envelope; coordinate/parameter magnitude <=1e6, widths in [1e-3,1e3], finite result magnitude <=1e12. At maximum tested 256 x 8 terms and 32 points, object wire lengths 47254 / 3612 / 3797 bytes (function, points, gradient). Not total process RAM. Refuse outside domain, mismatched axis/order/unit/domain, incompatible kinds, invalid bounds and budgets; no silent truncation. Both operations are numerical binary64, not exact/certified. Scientific assumptions and errors against an independent physical target not inferred. Source/checkpoint identity is not proof or signature.
