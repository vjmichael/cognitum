# COG-04R — affine Sturm–Liouville operands and separated boundaries

Scope: -(p u')' + v u = lambda w u on normalized unit interval. Affine rational diffusion p, weight w in [1/16,16], affine nonnegative potential v in [0,16]; rational denominator <=1024. Homogeneous separated Dirichlet, zero-flux Neumann, nonnegative Robin (outward p u' + alpha u=0) with finite alpha >0. Both endpoint kinds can be independently selected. Exact clamped cubic spline forms, weighted mass integral and gradient/potential stiffness integral plus positive Robin boundary terms. Dirichlet traces imposed by removing endpoint basis; natural flux imposed variationally, not pointwise at finite resolution. Pure Neumann with identically zero potential has exactly one constant zero mode, verified via exact row sums, LDL zero pivot and numerical zero tolerance. Exact rational forms and replay, floating Ritz spectrum with condition/residual/orthogonality guards.

Four nested uniform dyadic meshes (2,4,8,16 cells), 3 modes, max 15 knots, fractions with denominator <=64, bounded matrix and rational sizes. Uniform refinement is an explicit R qualification choice, not a claim of optimal adaptation; Q's residual-adaptive path is retained unchanged. Independent direct Gauss quadrature and whitened numerical eigensolver; independent continuum Prüfer phase ODE shooting and root finding, with tighter integration tolerance comparison. Analytic DD/NN/DN validation of reference. Neither analytic nor shooting values are used by Ritz assembly/solve. Final scaled eigenvalue error abs(error)/max(1,abs(reference)) <1e-5, including absolute zero-mode error. Numerical convergence/min-max checks are not rigorous eigenvalue enclosures. Natural boundary strong residuals reported, not claimed exactly zero.

Six cases: DD, NN, DN, RR, genuinely variable DD and variable NR; all 9 separated endpoint combinations receive exact-form tests. 19 dedicated tests per host; 24 level comparisons and six fresh-process native CPU/elapsed/peak measurements per host. Peak RSS/working set includes imports; reference excluded. Same-head Q predecessor receipt and source pins, no changed O/P/Q code, existing matrix only. Independent local numerical preflight: SciPy direct Gauss spline solver against DOP853 phase reference, six cases, all monotone; max final nonzero scaled error 3.624e-6, zero mode absolute approx 7.7e-14. This is a preflight, not integrated native acceptance. No production/Lu/accelerator admission, no indefinite forms, arbitrary geometry, nonlinear problems, non-self-adjoint operators, hard OS quotas, or certified continuum bounds.
