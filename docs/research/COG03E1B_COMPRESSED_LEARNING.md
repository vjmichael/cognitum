## Methods and fidelity
- CompHD [paper](https://ieeexplore.ieee.org/document/8824908/): actual native fit, native chunk-binding sum on matching operands, explicit one-bit packed position keys reconstructed one chunk at a time. No accidental sign-fold. Retain packed bipolar key and level tables, exact ternary encoder output including zero ties; folded prototypes stored as int16 only if final values exactly representable (fixture checks). Chunk keys counted in inference state and native full training state; underlying allocator overhead excluded. Float64 cosine output compared to native float32 predictions.
- SparseHD [paper](https://acsweb.ucsd.edu/~sasalama/papers/SparseHD.pdf): actual pinned SparseHD native sparsify at requested .25 removes .75 of dimensions because source computes round((1-sparsity)*D); class scatter is not in-place and changes no weights. Tested on untied positive fixture, native unchanged. Corrective reference uses round(sparsity*D), stable low-index ties, epoch mistake-update and explicit class or dimension pruning. Immutable per-row uint16/uint32 indices and values, norms and logical offsets; exact sparse cosine tested against dense float64 scores. Conventions deliberately differ from native defects, hence no native weight/score parity claim for custom training.
- QuantHD [paper](https://par.nsf.gov/servlets/purl/10169532): frozen ternary prediction state for each correction epoch, additive shadow counts, sign at boundaries; exact native weight and prediction agreement in tested configurations. Ternary zero preserved, not silently mapped to +1.
- LeHDC [paper](https://arxiv.org/abs/2203.09680): actual native fit with dropout_rate=0 and independent preencoded shadow-weight Adam with sign-forward gradient transfer and ReduceLROnPlateau. Exact native weights/predictions in tested dropout-free 4-epoch cohort; not full learned-encoder, dropout-enabled or original paper replication. Poor short-run digits accuracy retained. TorchHD docs [classifiers](https://torchhd.readthedocs.io/en/latest/classifiers.html).
- PackedTernary immutable bytes-backed positive/negative bit planes, zero padding, exact integer dot from four intersection popcounts, no full Q*C*D allocation. PackedLevels one-bit bipolar tables, float32 range clipping and round-to-nearest-even levels, per-sample/per-feature unpack/XOR accumulation and zero-sign ties. Compact packed arithmetic is appropriate for eventual FPGA reference vectors, but CPU Python loops are not optimized kernels. Workspace estimates are explicitly lower bounds; encoded query batch retained, plus output and NumPy temporaries. No actual accelerator implementation or physical energy claim.

## Matched held-out pilot
Eight dataset x seed x D processes, 112 recorded rows, digits/wine (sklearn bundled), fixed seeds 811/823, D128/512, 4 epochs (single pass Vanilla and CompHD), train-only minmax clipped feature scale; paired data/order, no test tuning. 1952 paired prediction events per matched arm (two repeated splits not independent). All four packed variants match native predictions on every event; all QuantHD and LeHDC weights also agree. Sparse dense-vs-sparse reference exact rank in all fixtures. All corrected sparse exported real-data rows attain .75 sparsity. Larger training/epoch/dropout, quantization calibration, original paper and domain validation remain open.
