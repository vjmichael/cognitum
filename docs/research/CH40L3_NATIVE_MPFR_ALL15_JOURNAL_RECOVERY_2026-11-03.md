# CH40-L.3 — Native MPFR child bounds, independent checker, and crash recovery

Date: 2026-11-03. **Scoped engineering acceptance: PASS. Scientific release: NO_GO.**

The CH40-L.3 benchmark used all fifteen original pinned frozen CH23/CH40-J mathematical datasets. Native system **libmpfr** was called directly with **256-bit directed rounding** from a new Python ctypes producer. Two child direct Firth/logistic plus Fisher-Hadamard upper-bound witnesses were calculated for one deterministic split per policy per dataset (30 splits, **60 native MPFR child upper witnesses**). These were independently verified by a **distinct rational/95-digit libmpdec interval arithmetic implementation** in a separate read-only audit module, without importing the MPFR producer. The auditor checked exact child midpoint coverage, frozen source SHA-256, 256-bit witness binding, parent-min inheritance, and local SHA-256 journal linkage.

**All 30 separate public-independent arithmetic audits passed.** Six focused tests passed, including actual subprocess SIGKILL at three publication stages (durable intent, torn append, post-append), repeated restart reconciliation, altered intent/tail refusal, and an altered bound refusal. The crashed publication reconciler completes exactly the intended event and avoids duplicate accepted events. The read-only verifier itself always rejects a pending or torn publication. This is an ordinary crash-consistency guarantee under the tested filesystem, **not an authenticated external journal anchor or proven hardware power-loss guarantee**.

Comparison: both policies had exactly one split and two native child evaluations on each of fifteen original cases, i.e. **equal work units, not equal CPU seconds**. Selective highest-frontier-upper policy lowered the global frontier in 2/15 cases: quasi_separated_n160_i00 by 0.06860011991263035; quasi_separated_n80_i00 by 0.03194016166111995. Breadth-first lowered 0/15 global frontiers at this limited one-split budget. No other case showed an improved global ceiling. CH40-L.2's earlier **two-split** reduction on the hardest case remains stronger; do not add the CH40-L.3 single-split improvement to that existing result.
