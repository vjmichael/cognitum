# E2D initial bounded research candidate — L19–L21

Base `ffe6eb3678a3317e511c19dfc47a3d37c8444811`. Research only. Independent implementation based on HDLouvain (https://arxiv.org/html/2610.30687), WaferHDC v2 (https://arxiv.org/html/2610.28949), and D2H-AD (https://arxiv.org/html/2606.13754). No author-code parity, proteomics, original wafer dataset or device claims.

HDLouvain: kNN union graph weighted by one minus normalized Hamming distance; NetworkX Louvain; majority representatives frozen on assignment, novelty threshold, bucket isolation, cap/refusal. Online lookup uses actual packed bytes and exact XOR/popcount with validated padding. Independent projected thermometer encoder instead of mass-spectrometry-specific ID/level preprocessing. Paired synthetic novel-mode and Wine pilot with raw Louvain/nearest neighbor and online k-means. Three seeds, fixed configuration, no threshold tuning. Novel data split deliberately excludes a mode from bootstrap using truth solely to construct the protocol; learner sees no labels. Report ARI/NMI and refusal (refusal is not a successful cluster), time excludes feature preprocessing; conventional k-means does not allocate novel clusters. Numeric array bytes are not complete process memory.

WaferHDC: normal-only fit and calibration, projected thermometer code, k-majority normal centers plus fixed normal bank, max distance score, temporary count memories and promotion on recurrence, coherence and abnormality, persistent-first matching, explicit fixed capacity/refusal. Count equations verified by explicit historical pairwise Hamming oracle. Synthetic 20×20 wafer-like masks and 15 descriptors, not original 202 descriptors. No WM-811K or native comparator fidelity; no raw stream retained, but normal reference bank retained. Promotion coverage and refusal reported separately from ARI (refusal treated as a shared label). Old-mode recovery metric is promotion status on recurrent mode, not independent identity fidelity. No eviction or forgetting yet.

D2H-AD: ID/level progressive random flips and XOR/strict-majority encoding. Inductive held-out adaptation, unlike transductive original. Pairwise cutoff computed from reference only; exclude reference diagonal, strict higher density, maximum query-reference distance on ties/no higher density, denominator floor 1. Compare identical score in normalized Euclidean and Hamming space; isolation forest, one-class SVM and independent HDC prototype control. Malignant-vs-benign data is a retrospective dataset stress test, not a medical application. Normal-only calibration 95th percentile; no test labels used in model training. Conventional model storage not measured; no speed ranking. Need paper transductive convention audit, matched tuning/capacity, additional datasets, conventional open-world controls, chronological WM-811K if accessible, scaling and true drift/forgetting. Preserve all prior code, production disabled.

Local quick gate: 20 dedicated tests, full inherited hosted gate expects 574 tests on each platform; local recovered suites only, not full repo.
