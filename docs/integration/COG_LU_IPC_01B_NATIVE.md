## Transport architecture

Reuses exact Lu workspace v0 Protobuf source Git blob `4e01d921197fb1c58c99958479b1cede36e13c9a` vendored/compiled in accepted 01A-R1. No new protocol, HTTP listener, TCP fallback, transport server, memory/model loader, model-facing tool, bridge to another provider, or Lu repository changes.

- `cognitum/mel/lu_ipc_native.py` exposes client-only OS carriers. Windows named pipe uses actual Win32 `WaitNamedPipeW`, `CreateFileW` (overlapped), `GetNamedPipeServerProcessId`, OS process handle/executable hash/creation FILETIME, and `OpenProcessToken`/TokenUser SID checks, all compared against *externally trusted* host-selected pins before any shared-key HMAC exchange. Reads/writes use bounded overlapped I/O with three-second event wait/cancel; client owns/cleans Win32 handles. Pipe name must be `\\\\.\\pipe\\lu-...`; the Lu Core source currently defines a `lu-ipc-` reserved prefix. A matching SHA/PID/SID/creation time does NOT verify Authenticode signer, trusted installer or protected OS publisher enrollment; those are Core/installer responsibilities and must remain mandatory.
- Linux `AF_UNIX` carrier checks an existing private `0700` Core-owned directory and `0600` Core-owned socket, refuses symlinks, connects with a three-second socket timeout, extracts true kernel `SO_PEERCRED` PID/UID/GID, and compares UID plus endpoint inode/device/owner/mode after connection to detect a replaced path. UID alone is not signed package authority. No auto-discovery, new local server or insecure `/tmp` fallback.
- The existing `AuthenticatedReadOnlyLuClient` from accepted 01A-R1 owns the canonical 256-KiB four-byte big-endian Lu frame + actual Protobuf/HMAC transcript, host session binding and single `HealthRequest -> HealthReport` call. `installed_core_health_preflight` composes OS native carrier and this client **only when the installed host supplies a trusted endpoint, process/UID pin, package SHA and OS-custodied handshake key**. It makes no model/resource/tool calls. The response explicitly marks signer validation out of scope of this Python client.
