## C05 + C10: bounded complete integer solution set

Historical fixture: integers x,y,z in 1..9, x<y<z, sum 12 and weighted sum x+2y+3z=29. Ground truth independently enumerates 729 triples. Expected exactly (1,5,6) and (2,3,7). A standalone C05 arm checks the same exact augmented-matrix product without a complete solution-set claim. The single-witness C10 baseline returns one SAT witness, not the complete set. Another standalone C10 complete-set arm exhaustively enumerates the original constraints. Cooperative arm uses C05 exact matrix multiplication of a nonsingular row transform and augmented equality matrix; the reviewed bridge verifies original equality identities/order and invertibility, retains non-equality constraints and integer domains, scales rational rows exactly, and submits transformed equivalent equations to C10. New typed complete-set result is checked by a separate direct enumeration implementation (not the kernel's satisfies method), including all cases, ordering, duplicate/omitted/forged rows, request digest and output cap. Equal accuracy with standalone complete enumeration is expected; no speed or novel solver claim. Alternate totals/weighted sums and an empty solution set test the same semantics.

## C13 + C16: conditional uncertainty propagation

Two mutually exclusive/exhaustive declared harmonic scenarios (initial position 1 m and 3 m, mass 2 kg, spring constant 8 N/m, zero initial velocity, terminal time pi/6) with equal priors and declared observation likelihoods 0.8 and 0.2. C13 standalone verifies posterior (0.8,0.2), no physical prediction. C16 prior-only baseline uses equal scenario weights. Cooperative bridge matches hypothesis IDs to physical scenarios (reverse order test), refuses user-provided weights, unmapped/duplicate IDs, impossible evidence. C16 requires an explicit mutually-exclusive/exhaustive-scenario declaration and returns typed conditional-model limitations. It performs actual SciPy integrations for each scenario, retains exact typed trajectories in a bounded result, and computes weighted endpoint mean/variance. Independent verifier replays native trajectory validation and analytically checks every sample position/velocity/energy against harmonic solution, plus separate pairwise variance formula. Closed form endpoints 0.5/1.5 m; prior mean 1 m, variance 0.25 m²; posterior mean 0.7 m, variance 0.16 m². Alternative likelihoods and a zero-weight case test response to different evidence. These are conditional finite-distribution moments, not empirical uncertainty bounds or calibrated real-world predictions. No unvalidated causal inference.
