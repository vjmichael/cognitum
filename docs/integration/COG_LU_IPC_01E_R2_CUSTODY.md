## Cognitum-owned implementation

1. `lu_ipc_native_custody.py`: strict immutable adapter that binds one original Lu `OriginRefs` workspace/turn/operation and original Core session to the reviewed MEL `Scope`. Reuses actual installed-host-facing Cognitum `OSCredentialBroker` (native Windows DPAPI or Linux kernel user keyring) and existing separate `LocalAuthenticatedRevisionCAS`. The adapter implements the exact original 01D `borrow_key`, `read`, `advance` interface, compares post-commit original revision and digest, and refuses wrong scope/key provider, missing OS keyring, stale restart, or replacing a pre-existing original operation. It does not provision secrets, create an authority, mint a Lu grant, publish, or run workers. Linux keyring can be unavailable in CI; it must **refuse explicitly, never fall back to plaintext**. Local CAS still does **not** supply an independent hardware/remote monotonic antirollback root; same OS account compromise or restoring both local files remains possible.
2. `lu_ipc_receipt_attestation.py`: strictly **proposed Cognitum-side envelope** for eventual Lu issuer handoff, *not* a Lu Core-supplied accepted schema. Requires external Ed25519 public key and Core package digest pins, externally supplied original grant SHA, original session/epoch, exact five-field Lu `OriginRefs`, exact original persisted terminal receipt SHA, original committed R6 outbox inventory SHA, short-lived issue window, and nonce. Checks exact canonical bounded signed bytes and real `cryptography` Ed25519 verification; rejects wrong/expired/foreign/downgraded/unknown claims. Private signing keys exist only in test fixtures, never production code. The pin **is just supplied data** until the installed Lu Core publisher/OS installer and protected enrollment independently vouch for it.
3. Extend accepted `lu_ipc_lifecycle.py` with exactly one locally HMAC-chained and independently-anchored `issuer_attestation` event, consumed only after an exact original APPLIED terminal, matched original Core reconciliation, and immutable R6 outbox snapshot. Deny repeat signed receipt/nonce across restart, cancellation/revocation/uncertainty, and any attempt to turn the record into actual output authorization. The record is a *provisional local audit observation*, not Lu's authoritative nonce ledger.
