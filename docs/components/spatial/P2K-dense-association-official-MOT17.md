# C15 T1 P2K — dense 2-D association and independent TrackEval evaluation

**Date:** 2026-10-28 (America/Phoenix)  
**Status:** standalone research implementation and official 3-full-sequence matched-box evaluation complete. **Result: negative vs conventional tracker identity assignments.** No Lu integration or production promotion.

## What actually ran

- P2J's six-by-six native Protobuf `spatial_identity_association.propose` remains unchanged and fails closed above six observations. We added `cognitum/spatial_p2k_dense_identity.py`, **a distinct optional, research-only dense 2-D box association adapter** using SciPy's Hungarian solver, bounded by <=64 boxes/frame, <=512 retained tracks, and at most 12 missing frames. It has no native Lu permission and cannot modify authoritative identities. It makes two simple predictions: (a) previous position and (b) linear extrapolation from the last two observations.
- Benchmark sequences were declared in code before scoring: **MOT17-02-DPM (600 frames), MOT17-05-DPM (837), MOT17-13-DPM (750)**. All **2,187** original frames and all **18,512** existing MPNTrack-predicted boxes were retained (7,464 + 4,659 + 6,389). There is no density-based frame cherry-picking or omission. For the three sequences respectively, 600, 208, and 467 frames exceed the legacy six-observation limit; the largest frame contains 18 objects.
- For each sequence, MPNTrack's original 10-column tracker predictions were read in two **separate roles**: a baseline stream preserving the original ID field; and an experimental stream in which ID was immediately removed. In the latter, only frame number, bounding geometry and sequential row order were passed into association. No original track ID, GT identity, GT geometry, annotation class or image pixel data was passed into the candidate algorithm. Output **changes only column 2 (track ID)**; every other output cell is unchanged and per-frame IDs are unique. Empty frames and observation gaps keep true frame numbers.
- Identity is never actually proven by same-category 2-D spatial proximity. All multi-object frames are flagged as lacking proof, even if local heuristic costs are well separated. The tracker labels were generated by **forcing deterministic top-one matches for research scoring**, which would not be permitted as a production authority policy. The near-tie diagnostic is a local-cost heuristic, not calibrated Bayesian uncertainty, global k-best or proof.
- Standard official `TrackEval` *HOTA*, *CLEAR* and *Identity* metrics, with original MOT17 GT/ignore/pedestrian preprocessing (`DO_PREPROC=True`), source-pinned to commit `12c8791b303e0a0b50f753af204249e622d0281a`, Git tree `ce583e59d96b33aad5f8f62149d96bc6bc4d8f96`. The 86-file source verification gate passes. The compatibility shim only restores the `np.float` alias for NumPy 2.x and does not edit the pinned evaluator. The GT/sequence metadata exactly matches the separately uploaded MOT17Labels archive. The evaluator ran **all three arms in one invocation**.
- Three complete sequences were chosen to include a high-density video, a lower-density video, and a mixed-density video, not as a randomized or preregistered held-out sample. The original MPNTrack detector/tracker output remains a powerful dependent control—this is **not a fair independent-detector evaluation** and cannot show full tracking architecture superiority.

## Adversarial synthetic tests and fail-closed design

- ID-stripping randomized original labels, seven boxes when old cap is six, changed object counts, one-to-one output IDs, appearance-free crossing, short gaps, expired long gaps, nonfinite input and invalid capacity/parameters.
- Crossing fixture demonstrates that constant-velocity tracking can maintain direction where position-only swaps trajectories; this does not substitute for genuine appearance embedding experiments or measured long-gap success.
- GT bytes and metadata cross-check with second archive; stages reject a nonempty directory, altered GT, >64 boxes/frame, nonfinite MOT data, stale official summary files, modified staged input, unavailable or changed pinned evaluator source, or a failing evaluator. The original P1 authority and research-only boundaries are not changed.
- Duration, gaps and max active object caps are fixed and are measured; no silent discarding of dense frames. The P2K adapter uses an **optional** SciPy+NumPy dependency, not a default Lu runtime dependency. An existing P2G optional-extra declaration was also relocated into the correct TOML table.

## Decision / next research milestones

**Retain P2K as experimental and default-off; do not promote to Lu.** The motion-only limitation is confirmed on these complete authentic sequences. Next: (a) run independent public MOT17 detections rather than MPNTrack's final boxes; (b) use pinned learned appearance embeddings and competent reference trackers like ByteTrack/BoT-SORT/DeepSORT; (c) match true detector and frame inputs, evaluate HOTA/AssA/IDF1/IDSW, occlusion recovery, speed, RAM/VRAM; (d) retain abstention/uncertainty and host security controls instead of forcing top one. A fair end-to-end P3 benchmark remains open; no proof of cognition/transformer augmentation gain is claimed.
