# Cognitum C15 T2 P2N — Bounded typed ontology and structural consistency

**Date:** 2026-10-28. **Scope:** Cognitum research-only. No changes to Lu or GitHub. Original P2M checkpoint and dataset archives retained.

## Engineering result

Added `proto/cognitum/spatial/v1/ontology_subset.proto`, independently compiled `cognitum/proto/spatial_ontology_subset_pb2.py`, and `cognitum/spatial_ontology_subset.py`. The Protobuf request includes an existing `StructureGraph`, declared ontology classes with parent relationships and schema source references, explicitly supplied type assertions, pairwise disjoint-class rules, and optional relation domain/range-like type rules. All output remains a read-only Protobuf audit, not a scene mutation or host authorization.

- **Supported:** strict finite acyclic taxonomy; monotonic subclass inheritance; class disjointness checks; admitted, source-linked node-type claims; declared direction-specific `PART_OF` and `CONTAINS` endpoint type rules; symmetric `CONNECTED_TO` rules; deterministic sorting and content digests; opt-in hypothetical semantics.
- **Safety:** exact schema version and known Protobuf fields, linked conversation scope, graph validation, duplicate and cycle rejection, bounded nodes/classes/axioms, source ID constraints, no promotion of hypothetical evidence to observed, no inferred physical geometry, and no inferred negative typing from lack of data.
- **Explicit omissions:** full OWL 2/RDFS semantics and owl:sameAs, OWL equivalences, unions/intersections, qualified cardinalities, arbitrary RDF imports, truth-maintenance, canonical knowledge-store mutation, real-world calibrated geometry, verified sensor authenticity or Lu-native tool approval.
- **Structural provenance:** source refs survive subclass and declared relation inference. These refs identify *claims*, not authenticated sensors or authority. Structural edges are interpreted only if a signature is explicitly supplied; neither kind text nor a part-of edge implies a physical category on its own.
- **Hypothetical handling:** by default, hypothetical nodes/assertions/edges cannot generate entailed types; `include_hypotheses=true` exposes hypothetical research conclusions, labeled as such, without authorizing actions.

## P2M-to-T2 link

`audit_p2m_handoff(feature_request, feature_response, handoff)` revalidates appearance-response bytes and reconstructs the expected handoff, then types only the hypothetical 2D identity nodes. It rejects changes to the T3 calibration or canonical-scene-blocking flags, altered 2D candidate labels, and fabricated structure edges. It cannot claim 3D object geometry, interior material structure or person identity from image-only features.

## Independent reference checks and reproducibility

`tests/test_c15_t2_p2n_ontology.py` covers ontology hierarchies and disjointness, source audit, role inference, missing and duplicated input, unknown serialized fields, hypothesis boundaries, tampering, and P2M integration. Randomized DAG subclasses are compared with **NetworkX** `descendants` and **RDFLib** `transitive_objects` over the same asserted `rdfs:subClassOf` graph. Additional seeded disjointness cases use a separate set-intersection oracle.

Run offline from the checkpoint root:

```bash
PYTHONPATH=. python -m pytest -q tests/test_c15_t2_p2n_ontology.py
PYTHONPATH=. python tools/run_c15_p2n_t2_ontology.py
PYTHONPATH=. python tools/verify_protobuf_schemas.py --require
PYTHONPATH=. python -m pytest -q tests/test_c15* tests/test_c13* tests/test_c14*
```

`rdflib` and `networkx` are **independent graph checks for the supported finite RDFS subclass subset**, not a whole-ontology OWL 2 reasoner run. The `owlrl` package is absent in this runtime; OWL 2 RL parity is **deferred** (not passed). The optional dependency extra is `spatial-ontology-parity`; production should pin exact wheels, transitive hashes, and security constraints. Source baselines: W3C OWL 2 Profiles, RDFLib OWL-RL. See `C15-T2-external-reasoner-backlog-v1.json`. The original six-item `C15-benchmark-backlog-v1.json` is unchanged.

## Why T2 stays independent of T3

Symbolic consistency is not spatial accuracy. No T3 voxel/occupancy assertion is generated by this module. Proposed future calibrated T2–T3 relations require actual depth, camera intrinsics/extrinsics, host authority, provenance, and separate independent geometry evaluation.
